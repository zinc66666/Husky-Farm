# Husky Farm — комната геймера

Idle-игра для Telegram Mini App: персонаж растёт, играя, и повышает свой
геймерский статус. Комната живёт по реальному времени — освещение, сезон и
погода совпадают с тем, что за окном у игрока.

Статичный сайт без сборки: `index.html` + ES-модули + `<canvas>`.
Ни одной зависимости, ни одного бандлера, ни одной картинки — вся графика
рисуется кодом.

## Что уже работает

- **Три зоны экрана без рамок:** сцена с комнатой, широкая кнопка сбора,
  панель навигации (Дом · Магазин · Задания · Друзья · Кошелёк).
- **Персонаж со спины** с анимациями: играет за компьютером, ходит по комнате,
  смотрит в окно, пьёт чай или отсутствует, когда игрок ничего не делает.
  Пол выбирается при первом запуске.
- **Живой мир:** фаза дня из часов устройства, сезон из даты, детерминированная
  погода (дождь, град, туман, снег) на сутки вперёд. Ночью комнату подсвечивает
  монитор.
- **Экономика:** доход от мощности ПК, накопление в банк с ограниченной
  ёмкостью, оффлайн-начисление, тапы и «Фокус».
- **Магазин:** 11 уровней ПК с растущим внешним видом и ~45 предметов декора.
  Каждая вещь перекрашивается в любой из 15 цветов.
- **Соседи:** процедурно сгенерированные комнаты, визиты, оценки по трём
  категориям, встречный поток гостей и бонусы к доходу.
- **Прогрессия:** 11 рангов геймера, ежедневные задания и цепочки достижений.

## Запуск локально

ES-модули требуют HTTP — `file://` падает на CORS:

```bash
python3 -m http.server 8080
# http://localhost:8080/
```

### Отладочные флаги

| Флаг | Что делает |
|---|---|
| `?debug=1` | fps, перерисовки слоёв, текущее состояние мира |
| `?t=03:30` | подменить время суток |
| `?season=winter` | подменить сезон (`winter`/`spring`/`summer`/`autumn`) |
| `?weather=hail` | подменить погоду (`clear`/`cloudy`/`rain`/`hail`/`fog`/`snow`) |
| `?act=window` | зафиксировать занятие персонажа |
| `?coins=1e9` | выдать монет |
| `?offline=6h` | притвориться, что игры не было 6 часов |
| `?seed=abc` | задать сид (лента соседей становится воспроизводимой) |
| `?gender=f` | пропустить онбординг |
| `?reset=1` | стереть сохранение |

## Деплой и подключение к боту

1. **Хостинг.** Включить GitHub Pages для этого репозитория
   (Settings → Pages → Deploy from a branch, ветка `main`, папка `/`).
   Файл `.nojekyll` уже лежит в корне, все импорты относительные — игра
   работает и в подпапке вида `https://<user>.github.io/Husky-Farm/`.

2. **Бот.** Создать бота у [@BotFather](https://t.me/BotFather) (`/newbot`),
   затем `/newapp` → выбрать бота → указать URL со страницы Pages.
   После этого мини-приложение открывается по `t.me/<bot>/<app>`.

3. **Кнопка в чате.** Либо `/setmenubutton` у BotFather, либо запустить
   готовый бот из репозитория — он сам настроит меню и пришлёт кнопку:

   ```bash
   BOT_TOKEN=123456:ABC... \
   WEBAPP_URL=https://<user>.github.io/Husky-Farm/ \
   node bot/bot.mjs
   ```

   Боту нужен только Node 18+, зависимостей нет.

Игра работает и в обычном браузере: весь Telegram-специфичный код спрятан за
фасадом `src/platform/telegram.js` с полным фолбэком.

## Структура

```
index.html  styles.css              каркас трёх зон и визуальный язык
bot/bot.mjs                         бот, открывающий мини-приложение
src/core/                           цикл, шина событий, PRNG, формат, хранилище
src/platform/                       фасад Telegram WebApp, размеры и safe-area
src/state/                          схема сейва, миграции, стор, селекторы
src/game/                           экономика, ранги, задания, мир, соседи, гости
src/data/                           каталог вещей, слоты комнаты, палитры, сезоны
src/render/                         слои, материалы, свет, частицы
src/render/themes/vector/           текущая тема: комната, мебель, персонаж
src/ui/                             экраны и компоненты интерфейса
src/net/                            граница «сети»: локальный и серверный адаптеры
```

Ключевая абстракция — `RoomModel`: рендерер не знает про стор и умеет рисовать
только эту структуру. Поэтому комната соседа достаётся бесплатно, а реальный
бэкенд позже отдаёт ровно тот же формат.

Смена стиля на пиксель или 3D — это новый файл темы с теми же ключами
(`src/render/theme.js`), игровая логика не меняется.
